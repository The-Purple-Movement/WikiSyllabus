# PCCSL507: Networks Lab

**Course type:** Lab · **Credits:** 2

## Course Objectives

- To provide hands-on experience in network programming using Linux System calls and network monitoring tools.
- To comprehend the implementation of network protocols and algorithms, and configuration of network layer services using network simulators.
