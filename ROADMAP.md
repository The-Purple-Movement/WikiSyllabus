# Roadmap: the contribution engine

*WikiSyllabus is the data layer of the [Purple Movement](https://github.com/deepusnath/purple-movement-constitution): every file here becomes an AI study companion in [Beyond Syllabus](https://github.com/The-Purple-Movement/Beyond-Syllabus) within hours (the sync workflow runs every 6 hours). The repo's job is therefore an engine problem: make contributing easy, fast to merge, and visibly needed.*

**State of the corpus (July 2026):** 2,207 files, 18 universities, 99% frontmatter compliance. One university (KTU) is 79% of everything. Community appetite is proven: 20+ open university requests and multiple contributor PRs waiting on review.

## Phase 0: unclog the engine (weeks)

The single biggest threat to this project is a contributor who waits weeks for a merge and never returns.

- [ ] **Adopt validation CI** (`scripts/validate.py` + the PR workflow in this branch): every PR gets an automatic pass/fail in seconds, so review becomes a skim, not an audit
- [ ] **Triage every open PR** and merge or close with reasons; nothing stays unanswered
- [ ] **Set the merge SLA**: first response within 72 hours, and say so in CONTRIBUTION.md
- [ ] **Publish [COVERAGE.md](./COVERAGE.md)** (generated by `scripts/coverage.py`) so the gaps are visible; regenerate on merge
- [ ] Recruit 2 to 3 co-maintainers with merge rights from proven contributors; one maintainer is a bottleneck by design

## Phase 1: pay the quality debt (months 1–2)

The validator found 202 legacy errors; all are mechanical:

- [ ] Rename non-conforming paths (uppercase branch folders like `university-of-oxford/CS/`, stray depths); each rename is one `git mv`, labeled as good first issues
- [ ] Merge the duplicate university: `kerala-technical-university` (2 files) into `a-p-j-abdul-kalam-technological-university`
- [ ] Fill missing frontmatter fields flagged by the validator (~24 files)
- [ ] Replace `@backfill-needed` placeholder credits with real contributor handles from git history
- [ ] Work through the 579 warnings (near-empty bodies, mismatched fields) as a labeled cleanup series

## Phase 2: the coverage campaign (months 2–6)

- [ ] **Adopt Your University**: through the μLearn campus network, each participating campus owns its own university's syllabus: current scheme, all branches, all semesters. The pitch is self-interest: your syllabus in this repo means your AI study companion works
- [ ] Convert the 20+ open university-request issues into checklists (branch by branch, semester by semester) so partial contributions land
- [ ] Complete the Kerala core beyond KTU: MG University, CUSAT, Calicut, Kerala University to full current-scheme coverage
- [ ] International entries grow only with maintainers who can verify them; accuracy beats flags on a map

## Phase 3: freshness (months 6–12)

The founding vision is continuous currency with every university's latest syllabus:

- [ ] **Scheme watch**: a tracked issue per major university listing its current scheme year vs ours; when a university publishes a revision, the issue opens automatically from a yearly checklist
- [ ] Stale-scheme labels in COVERAGE.md (a 2019 scheme in 2026 gets flagged)
- [ ] Sync health check: alert if the Beyond-Syllabus sync fails twice consecutively
- [ ] Year-end coverage report: what was added, by whom, what went stale

## Metrics that matter

- **Time from PR opened to first maintainer response** (target: under 72 hours)
- **Contributors whose second PR arrives** (the engine's true health)
- Requested universities with at least one complete current-scheme semester
- Freshness: share of universities whose latest scheme is present

Not metrics: total file count alone, stars, number of universities with token single files.
